# BRITTANY (Biometric RecognITion Through gAit aNalYsis)

Author(s): ClaudiaAlvarez

Maintainer(s): ClaudiaAlvarez

License: L-GPL v3

Source: <https://github.com/ClaudiaAlvarezAparicio/brittany>

Dependencies:

-   tensorflow_catkin
-   catkin_simple
-   tensorflow_ros_cpp
-   petra

Description: BRITTANY is a tool that allows a Biometric recognition
through gait analysis by using LIDAR sensors. The system is based on a
classification neural network that allows identifying 5 different users
of the system or intruders in it.
