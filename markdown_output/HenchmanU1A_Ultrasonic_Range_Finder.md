# HenchmanU1A Ultrasonic Range Finder Overview

HenchmanU1A is a new generation, long distance ranging Time-of-Flight
module based on ultrasonic technology. The module targets the need for
high performance very compact sound distance measurement sensors for
applications such as unmanned autonomous vehicles where

## Apllications

-Fully integrated module

-Fast and accurate long distance ranging

-30cm to 240cm distance measurement

-4Hz ranging frequency

-4 distance sensor with 20 deegres FOV

-Easy integration

-Software driver and code examples for turn key ranging

-Single power supply(12V)

-Plug and play USBHID communication

-Fully robot operating system compatible

-Ready RVIZ configurations
