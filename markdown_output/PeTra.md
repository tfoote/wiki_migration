# PeTra (People Tracking)

Author(s): ClaudiaAlvarez

Maintainer(s): ClaudiaAlvarez

License: L-GPL v3

Source: <https://github.com/ClaudiaAlvarezAparicio/petra>

Dependencies:

-   tensorflow_catkin
-   catkin_simple
-   tensorflow_ros_cpp

Description: PeTra is a tool that allows detecting and tracking people.
The system is based on a CNN that uses an occupancy map constructed from
the readings of a LIDAR sensor.
