## Description

This package will launch all of the necessary components to perform the
2011 AAAI LfD Challenge Breakfast for Two Task.

### Configuration Files

The config directory contains two yaml scripts that contain the expected
configuration.

executive_script.yaml: provides the high level task specification for
the aaai_lfd_demo_executive listing which location of the base the
objects can be reached from as well as with which arm

object_locations.yaml: provides instructions for the
openloop_object_manipulation and describes how the arm should first the
position of the approach and then the position of the grasp.
