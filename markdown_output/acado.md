[ ACADO Toolkit](http://www.acadotoolkit.org/ ) is a software
environment and algorithm collection for automatic control and dynamic
optimization. It provides a general framework for using a great variety
of algorithms for direct optimal control, including model predictive
control, state and parameter estimation and robust optimization. ACADO
Toolkit is implemented as self-contained C++ code and comes along with
user-friendly Matlab interfaces. The object-oriented design allows for
convenient coupling of existing optimization packages and for extending
it with user-written optimization routines.

The ACADO Toolkit is made available in ROS Indigo by
[ClearpathRobotics](ClearpathRobotics). You can install it on Ubuntu
like so:



```
sudo apt-get install ros-indigo-acado
```
