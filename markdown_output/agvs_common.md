## Package Summary

This package contains the different controllers and launch files for the
[Agvs robot](Robots/Agvs), shared for real robot and simulation.

-   Autor: Robotnik Automation
-   License: BSD
-   Source: git <https://github.com/RobotnikAutomation/agvs_common.git>

![AGVS RViz\|width=\"600px\"](attachment:agvs_rviz.png)

## List of packages

### agvs_description

This package contains the robot model (urdf, meshes, \...).

### agvs_pad

This package is intended to control the robot by a pad or joystick.
