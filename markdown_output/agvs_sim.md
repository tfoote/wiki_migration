## Package Summary

This package contains the different controllers and launch files for the
[Agvs robot](Robots/Agvs) simulation.

-   Autor: Robotnik Automation
-   License: BSD
-   Source: git <https://github.com/RobotnikAutomation/agvs_sim.git>

![AGVS Gazebo\|width=\"600px\"](attachment:agvs_gazebo.png)

## List of packages

### agvs_control

This package contains the configuration files for the Gazebo controllers
used by the model.

### agvs_gazebo

This package contains the configuration files to launch the Gazebo
environment along with the simulated robot.

### agvs_robot_control

This package contains the simulated controlled that interfaces with
Gazebo controllers.

### agvs_sim_bringup

This package contains all the launch and config files to launch all the
needed packages to load the simulated environment.
