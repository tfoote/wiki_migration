# Package Summary

Basic ROS support for [Ainstein](https://ainstein.ai/) radars as well as
simulation, visualization and processing tools and utilities for working
with generic radar data.

-   Maintainer status: developed
-   Maintainer: Nick Rotella <nick.rotella AT ainstein DOT ai>
-   Author: Nick Rotella
-   License: BSD
-   Bug / feature tracker:
    <https://github.com/AinsteinAI/ainstein_radar/issues>
-   Source: git <https://github.com/AinsteinAI/ainstein_radar.git>
    (branch: master)

# Devices Supported

This driver supports the following radar products and development
prototypes:

-   [O79 (Ainstein Vehicle Imaging Radar)](https://ainstein.ai/o-79/)
-   [K77 (Ainstein 77 GHz Automotive Safety Radar)](https://ainstein.ai/vehicle-radar/kanza-77-3/)
-   [T79 (Ainstein 79 GHz Automotive Safety Radar)](https://ainstein.ai/vehicle-radar/t-79/)
-   [SRD-D1 (Ainstein Drone Short Range Detection Radar)](https://ainstein.ai/srd-d1/)
