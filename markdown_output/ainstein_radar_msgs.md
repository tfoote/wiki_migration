## Overview

This package collects custom ROS messages for Ainstein radar sensors,
however most are also generic enough to be used with other radar
sensors.

## Message Types

-   [ainstein_radar_msgs/msg/RadarTarget](https://docs.ros.org/en/rolling/p/ainstein_radar_msgs/msg/RadarTarget.html)
-   [ainstein_radar_msgs/msg/RadarTargetStamped](https://docs.ros.org/en/rolling/p/ainstein_radar_msgs/msg/RadarTargetStamped.html)
-   [ainstein_radar_msgs/msg/RadarTargetArray](https://docs.ros.org/en/rolling/p/ainstein_radar_msgs/msg/RadarTargetArray.html)
-   [ainstein_radar_msgs/msg/RadarInfo](https://docs.ros.org/en/rolling/p/ainstein_radar_msgs/msg/RadarInfo.html)
-   [ainstein_radar_msgs/msg/RadarAlarm](https://docs.ros.org/en/rolling/p/ainstein_radar_msgs/msg/RadarAlarm.html)
-   [ainstein_radar_msgs/msg/RadarAlarmStamped](https://docs.ros.org/en/rolling/p/ainstein_radar_msgs/msg/RadarAlarmStamped.html)
-   [ainstein_radar_msgs/msg/RadarAlarmArray](https://docs.ros.org/en/rolling/p/ainstein_radar_msgs/msg/RadarAlarmArray.html)
