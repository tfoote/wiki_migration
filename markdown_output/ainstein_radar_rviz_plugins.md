## Overview

This package contains plugins for natively displaying custom Ainstein
radar messages in RViz, however any package which publishes the
mostly-generic ainstein_radar_msgs types can benefit from these RViz
plugins.

## Plugins

Currently, RViz plugins exist for the following custom message types:

-   \<\<MsgLink(ainstein_radar_msgs/RadarTargetArray)\>\>
-   \<\<MsgLink(ainstein_radar_msgs/RadarInfo)\>\> (WIP)
