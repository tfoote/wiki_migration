This package allows setting the (virtual) Python environment for your
package including the Python version and pip libraries via a simple
requirements.txt file. It is based on
<https://github.com/locusrobotics/catkin_virtualenv/blob/master/README.md>.
See
[README](https://github.com/esol-community/ament_virtualenv/blob/master/README.md)
for package documentation.
