## Overview

The arbotix_controllers package contains several controllers that add
additional layers of ROS interface onto the basic structure of
[arbotix_python](arbotix_python).

-   one_side_gripper_controller.py
-   parallel_gripper_controller.py
-   parallel_single_servo_controller.py

These will likely be merged into a single gripper driver before our 1.0
release. This single driver will also likely be moved to the
arbotix_python package.

The previously included controllers have been merged into
arbotix_python.
