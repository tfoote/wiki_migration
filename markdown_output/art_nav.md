## ROS Nodes

This package contains ROS nodes for navigating the ART autonomous
vehicle.

```clearsilver
node.0 {
 name = commander
 desc = Global path planning for the ART vehicle.
 sub {
  0.name = navigator/state
  0.type = art_msgs/NavigatorState
  0.desc = current navigator state information
 }
 pub {
  0.name = navigator/cmd
  0.type = art_msgs/NavigatorCommand
  0.desc = way-point orders for navigator
 }

param {
group.0 {
name=Initial Parameters
0.name= ~frame_id
0.default= "/map"
0.type= string
0.desc= Frame of reference for road map.
1.name= ~mdf
1.default= ""
1.type= string
1.desc=Mission Definition File name (required).
2.name= ~mission_state
2.default= ""
2.type= string
2.desc=Mission state save file name (default: none).
3.name= ~rndf
3.default= ""
3.type= string
3.desc=Route Network Definition File name. Required, but can be defined anywhere within the enclosing namespace.
}
}
}
```

#### Examples

Run the ART commander, sending \`navigator/cmd\` messages.

```
rosrun art_nav commander _rndf:=road_map.rndf _mdf:=mission_ckpts.mdf
```

#### Examples

Run the ART navigator, accepting \`navigator/cmd\` messages.

```
rosrun art_nav navigator
```

```clearsilver
node.0 {
 name = estop
 desc = Graphical client for navigator E-stop control.
 sub {
  0.name = navigator/state
  0.type = art_msgs/NavigatorState
  0.desc = current navigator state
 }
 pub {
  0.name = navigator/cmd
  0.type = art_msgs/NavigatorCommand
  0.desc = navigator orders
 }
}
```

#### Examples

Run GUI for sending Run and Pause orders to the navigator.
```
rosrun art_nav estop.py
```
