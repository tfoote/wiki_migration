## ROS Nodes

This package contains a ROS node for controlling ART autonomous vehicle
servo interfaces, including brake, shifter, steering and throttle.

```clearsilver
node.0 {
name = pilot
desc = Servo device control for the ART vehicle.
sub {
0.name = pilot/drive
0.type = art_msgs/CarDriveStamped
0.desc = driving command

1.name = imu
1.type = sensor_msgs/Imu
1.desc = estimate of vehicle accelerations

2.name = odom
2.type = nav_msgs/Odometry
2.desc = estimate of vehicle position and velocity

3.name = brake/state
3.type = art_msgs/BrakeState
3.desc = brake status information

4.name = shifter/state
4.type = art_msgs/Shifter
4.desc = shifter status: current gear, relay values

5.name = steering/state
5.type = art_msgs/SteeringState
5.desc = steering status information, including wheel angle

6.name = throttle/state
6.type = art_msgs/ThrottleState
6.desc = throttle status information
}
pub {
0.name = pilot/state
0.type = art_msgs/PilotState
0.desc = pilot node status information

3.name = brake/cmd
3.type = art_msgs/BrakeCommand
3.desc = brake commands

4.name = shifter/cmd
4.type = art_msgs/Shifter
4.desc = gear shift requests

5.name = steering/cmd
5.type = art_msgs/SteeringCommand
5.desc = steering requests

6.name = throttle/cmd
6.type = art_msgs/ThrottleCommand

}
```

#### Examples

Run the ART pilot node, accepting `pilot/drive` messages.

```
rosrun art_pilot pilot
```
