## Usage

This package provides a way to control the thrust output

## Details

'q' - quit

'w' - Throttle Up

's' - Throttle Down

'z' - Zero Throttle

## Known Bugs

This should not be considered production quality or even usable.

## Example

The controller can be started by running:

```shell
rosrun asctec_ctrl controller.py
```
