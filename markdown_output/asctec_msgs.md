## Usage

This package provides custom messages that have the same structure as
the
[AscTec AutoPilot](http://www.asctec.de/asctec-hummingbird-autopilot/)
documented specifications.

## Details

All messages are explained in Appendix C of the
[ AscTec Pelican Manual]( http://robotics.ccny.cuny.edu/wiki/AscTec/Docs ).
