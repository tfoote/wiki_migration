## Description

This package features gazebo models of the room where the experiments
were taken, the whole floor and the robot.

It contains the following models:

-   **institut: **A model of the whole floor
-   **mild: **The robot used
-   **room_epxeriments_manual: **manually created model based on the
    floor plan in real scale
-   **room_experiments_manual_rearranged: **same, but different
    arrangement
-   **room_experiments_manual_rearranged_pascal: **later model of the
    same room
-   **room_experiments_slam: **same room but walls are derived from a
    SLAM map.

## Usage

To use these models with gazebo, copy the according folder to
\"/.gazebo/models\" following
[this guide](http://gazebosim.org/tutorials?tut=build_world&cat=build_world#AddingModelfromtheModelDatabase).

You can now start gazebo and insert the model into your world.
