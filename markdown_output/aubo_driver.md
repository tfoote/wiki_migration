## Overview

This package is part of the [aubo_robot](aubo_robot) program.

## Usage

Connect to the real robot with network, launch the following and make
contact:

```
roslaunch aubo_driver aubo_i5_bringup.launch robot_ip:=xxx.xxx.xxx.xxx
```

Then,you can control it by the teleop panel.
