## Overview

This package is part of the [aubo_robot](aubo_robot) program. It is the
MoveIt! configuration for the AUBO-i5 arm, generated automatically by
the MoveIt Setup Assistant.

## Getting Started



```wiki
 Be sure to install the `moveit_simple_controller_manager` package in addition to those mentioned below.
```



Install the package from package management, and run the !MoveIt!
planning demo: 

```
$ sudo apt-get install ros-indigo-aubo-i5-moveit-config

$ roslaunch aubo_i5_moveit_config demo.launch
```



This is not a real simulation, just a demonstration of the planning
capability and the !MoveIt! and RViz integration. For true simulation of
a AUBO-i5, see the [aubo_gazebo](aubo_gazebo) package.
