## Overview

The
[DeepRacer Interfaces ROS package](https://github.com/aws-deepracer/aws-deepracer-interfaces-pkg)
is a foundational package that creates the custom service and message
types that are used in the core AWS DeepRacer application. These
services and messages defined are shared across the packages that are
part of the AWS DeepRacer application. More details about the
application and the components can be found
[here](https://github.com/aws-deepracer/aws-deepracer-launcher).
