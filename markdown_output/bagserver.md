## Overview

The goal for this package is universal access to data stored in
messages. The server will provide flexible access to the information
stored in bag files. The package will mainly fulfill the following use
cases:

1\. Provide random access to messages (short-term at run time and
long-term) 1. Define universal naming of messages/data elements 1. Build
linking framework independent of the data model 1. Implement universal
query language to specify messages, traverse links, etc
