# Introduction

bebop_driver is a ROS driver for
[Parrot Bebop drone](http://www.parrot.com/ca/products/bebop-drone/)
(quadrocopter), based on Parrot's official
[ARDroneSDK3](https://github.com/Parrot-Developers/ARSDKBuildUtils).
This package is part of [bebop_autonomy](bebop_autonomy).

-   Documentation: <http://bebop-autonomy.readthedocs.org/>
