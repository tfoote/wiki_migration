# but_velodyne

Packages for Velodyne 3D LiDARs tested with Velodyne HDL-32E provided by
Robo@FIT group.

-   [but_velodyne_proc](but_velodyne_proc) - 3D laser scanner data
    processing.
-   [but_calibration_camera_velodyne](but_calibration_camera_velodyne) -
    tools for calibration camera with Velodyne LiDAR sensor.
-   but_velodyne_odom - odometry estimation based on point clouds and
    RGB
