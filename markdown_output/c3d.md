## The C3d Format

C3d is motion capture format that records the position of markers in
3-dimensional space. Full documentation is available
[here](http://www.c3d.org/).

This package contains a library for reading c3d files in Python. It is
based on code from
[Noisy Gecko's c3d_convert.py](http://blog.noisygecko.com/c3d_convert.py).

This package can be used independently, but is mainly for use by
[mocap_point_cloud](mocap_point_cloud).
