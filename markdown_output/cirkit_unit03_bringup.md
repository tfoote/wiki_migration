## Overview

This package contains supporting launch files for bringing up
CIR-KIT-Unit03\'s ROBOT\'s drivers.

For usage, please see the [Robots/CIR-KIT-Unit03](Robots/CIR-KIT-Unit03)
page.

### Launch files

The \`launch\` folder contains launch files for setting up
CIR-KIT-Unit03\'s drivers, such as the UTM-30LX
([hokuyo_node](hokuyo_node)) and YVT-X002 ([hokuyo3d](hokuyo3d))).

The launch files for communication with CIR-KIT-Unit03 MCU live in the
[cirkit_unit03_base](cirkit_unit03_base) package.
