## Overview

![Clober URDF\|width=400](attachment:clober_description/clober_description.png)

**Clober Description** contains the URDF model files for Clober robot
simulations. It can be used to express additional extension models or
accessories onto the research robot platform.

## Clober e-Manual

-   [Clober e-manual on gitbook](https://app.gitbook.com/@clobot-git/s/clober-manual/)

## URDF Files

-   \`clober.urdf.xacro\` - Defines the \`clober\`\'s specifications of
    links and joints.
-   \`clober.gazebo.xacro\` - Defines the \`clober\`\'s parameters of
    link and library of drive, imu and lidar.
-   \`d435.urdf.xacro\` - Defines the depth camera \`d435\`
-   \`tim571.urdf.xacro\` - Defines the lidar sensor \`tim571\`
