## Overview

This package contains launch files for the [gmapping](gmapping) node for
SLAM without navigation to create a map.

## Applications

- **`launch/2dslam.launch`**: Starts the gmapping node.

## Building Blocks

- **`launch/2dslam.xml`**: Holds a specific configuration of the
  [gmapping](gmapping) node. Designed to be included by applications
  that wish to run [gmapping](gmapping) on the [Care-O-bot](care-o-bot).
