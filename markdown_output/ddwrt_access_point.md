## Overview

Provides a node for controlling a Linksys WRT610Nv2 (or compatible)
access point with the [dd-wrt](http://www.dd-wrt.com/) firmware. It has
been tested with the firwmare version
[dd-wrt.v24-15693_NEWD-2_K2.6_mini_wrt610nv2.bin](http://www.dd-wrt.com/dd-wrtv2/downloads/others/eko/BrainSlayer-V24-preSP2/11-06-10-r15693/broadcom_K26/dd-wrt.v24-15693_NEWD-2_K2.6_mini_wrt610nv2.bin).
Other dd-wrt firmware versions and access point models may be compatible
with this node provided the web interface is the same.

See [linksys_access_point](linksys_access_point) and
[access_point_control](access_point_control) for more details.
