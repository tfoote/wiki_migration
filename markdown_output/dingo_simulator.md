## Installation

To work with simulated Dingo on your own machine, make sure if have
[ROS Melodic](melodic/Installation) set up, and install the metapackages
for desktop and simulation:

```
sudo apt-get install ros-melodic-dingo-simulator ros-melodic-dingo-desktop
```

You should now be good to go!
