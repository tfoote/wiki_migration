## Wandering

To launch the wandering algorithm, just execute the following command:


```
roslaunch dm_lizi wandering.launch
```



This will bring up gazebo simulation environment with lizi, and open an
rqt plugin displaying the running decision making model:

![Lizi Decision Making Model\|width=790](attachment:lizi_dm_graph.png)
