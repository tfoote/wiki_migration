## Requirements

The DX100 software will work on most
[DX100 robot controllers](http://motoman.com/datasheets/DX100%20Controller.pdf).
However, the options below must be specially ordered from Motoman in
order to support ROS-Industrial integration. Email
[mailto:swri-ros-pkg-dev@googlegroups.com](mailto:swri-ros-pkg-dev@googlegroups.com)
for more detailed information.

-   Controller system software DS1.62.xx-03 (or higher DSx.xx-03
    version) required
-   Motoplus Advanced SDK required to develop integration for additional
    Motoman arms (Requires a PC with Windows XP - 7)
-   MotoROS robot parameters provided by Motoman. This includes modified
    controller system-software, as well as specific robot parameters
    that can only be set by a Yaskawa Motoman representative.
-   For more information, please contact Yaskawa Motoman and inquire
    about the DX100 ROS package (part# 161436-1)
