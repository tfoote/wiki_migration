## Usage

`roslaunch dynamics_markers pr2_both_arms.launch` Start
dynamics_markers with support for both arms. `roslaunch
dynamics_markers pr2_l_arm.launch` Start dynamics_markers for left arm
only. `roslaunch dynamics_markers pr2_r_arm.launch` Start dynamics
markers for right arm only.

In rviz add a new display of type `Markers` with `Marker Topic` set
to `/dynamics_markers/markers`
