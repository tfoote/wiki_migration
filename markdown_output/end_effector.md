## Overview

This package provides a ROS-based set of standard interfaces to command
robotics end-effectors in an agnostic fashion.

The main documentation is here:
<https://advrhumanoids.github.io/ROSEndEffectorDocs/>

Doxygen-generated documentation about the API can be found here:
<https://advrhumanoids.github.io/ROSEndEffector/index.html>
