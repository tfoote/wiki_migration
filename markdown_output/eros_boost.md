## Overview

This package is a component of eros'
[toolchain bridge](eros/ToolchainBridge). It provides a lightweight
version of boost suitable for embedded boards.

## Tested

-   Native: linux
-   Cross-Compile: arm, mingw32

## Selected Packages

You can find the list of selected packages in the `CMakeLists.txt`. If
you have a good case for expanding eros' selection of packages, then
[contact](eros/Troubleshooting) the eros developers.
