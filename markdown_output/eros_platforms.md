## Overview

This package provides a library of cmake platform configuration modules
for popular platform configurations. They can be found in the
`eros_platforms/library` folder.

## Usage

Eros pre-defined platforms can be conveniently selected and managed via
the [rosplatform](eros_python_tools/rosplatform) script.

## Notes

Eros platforms are the place to define flags and settings appropriate
for your particular platform such as cflags, lflags, install prefix
etc - refer to the code api for more information if interested.
