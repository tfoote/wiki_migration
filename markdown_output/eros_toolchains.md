## Overview

This package provides a library of cmake toolchain modules for popular
toolchain configurations. They can be found in the
\`eros_toolchains/library\` folder.

## Usage

Eros pre-defined toolchains can be conveniently selected and managed via
the [rostoolchain](eros_python_tools/rostoolchain) script.

## Notes

Eros toolchains also predefine a few useful variables - refer to the
code api for more information if interested.
