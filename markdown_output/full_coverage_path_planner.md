Full Coverage Path Planner (FCPP)

## Overview

This package provides an implementation of a Full Coverage Path Planner
(FCPP) using the Backtracking Spiral Algorithm (BSA), see \[1\].

This packages acts as a global planner plugin to the Move Base Flex
package (<http://wiki.ros.org/move_base_flex>).

![\|width="600"](attachment:fcpp_robot_0_5m_plus_tool_0_2m.png)

The user can configure robot radius and tool radius separately:

![\|width="300"](attachment:robot_plus_tool.png)

Source code at <https://github.com/nobleo/full_coverage_path_planner>.
