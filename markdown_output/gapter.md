## Overview

[Gapter EDU](http://edu.gaitech.hk/gapter/index.html) is designed by
[Gaitech](http://www.gaitech.hk) specially for research and education.
It comes with a documentation and software packages that allow a user to
easily start working and developing with Gapter. More information about
Gapter and its mechanical specification available
[here](http://edu.gaitech.hk/gapter/overview-and-features.html)

## Documentation

This stack contains core documentation for the [Gapter](Robots/Gapter).

-   [gapter_pilot](gapter_pilot) - Gapter pilot
-   [teleop_key](teleop_key) - contains gapter teleoperation
