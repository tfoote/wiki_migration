# Overview

Multi robot simulation with concert framework.

## Execution

### Starting Gazebo Concert



```
> roslaunch gazebo_concert concert.launch --screen
```



### Teleoperate a robot

-   Start [rocon_remocon](rocon_remocon)



```
> rocon_remocon
```



-   Select Concert

-   Start Concert Teleop and select a robot
