## Summary

This package is a work in progress. The goal is to be able to create
PR2/Turtlebot-like dashboards without an intimate knowledge of RX.

The system is built around having
<<MsgLink(diagnostic_msgs/DiagnosticArray)>> messages published by
the robot drivers.

## Documentation

Full documentation is coming, but for an example to work from, check out
[rflex_dashboard](rflex_dashboard).
