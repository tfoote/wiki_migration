## About

Genjava is a message generator in the same vein as gencpp, genpy,
genlisp.

It is not yet official - right now it is both too slow (has a compile
step) and has a large dependency (openjdk) which make its consideration
as an official generator non-ideal.

Nonetheless it is quite usable for generating java maven artifacts for
message packages that are in your source workspace (making custom
message generation significantly easier), and also has some scripts and
a cmake api for generating messages from existing deb installed
packages.
