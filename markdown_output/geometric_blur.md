## Overview

geometric_blur is a library for geometric blur descriptor invented by
Alex Berg. It works the best by calculating descriptor on top of the
Berkeley natural boundary detector. A most recent paper, Object
Detection using a Max-Margin Hough Transform by Subhransu Maji and
Jitendra Malik, presents a state-of -the-art result on ETHZ shape
dataset by using geometric blur with Berkeley natural boundary detector.
