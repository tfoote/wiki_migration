This package contains the orocos typekit for the
[geometric_relations_semantics](http://www.ros.org/wiki/geometric_relations_semantics).

This is a third party package with
[external documentation](http://www.orocos.org/wiki/geometric-relations-semantics-wiki/).

The external documentation offers background material, the explanation
of the software design, API documentation, Quick start guide (including
installation instructions), user guide, tutorials, FAQs, and use cases.
