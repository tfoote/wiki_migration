## Overview

This package exposes a library that contains classes and methods to
represent and work with primitive geometric shapes. These shapes can be
static (plane) or can have a pose attached to them (sphere, box,
cylinder, mesh) and then they are referred to as bodies. The package is
widely used throughout the arm navigation stack to evaluate point
containment, ray intersection and constraint region representation.
