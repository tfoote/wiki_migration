## Overview

This package contains resources and launch files for scenarios used in
gazebo simulation. The following is a list of available launch files:

- [rolling_landscape_120m.launch](https://github.com/tu-darmstadt-ros-pkg/hector_gazebo/blob/hydro-devel/hector_gazebo_worlds/launch/rolling_landscape_120m.launch):
  A 120m x 120m landscape with rolling hills. Never runs faster than
  realtime.
- [sick_robot_day_2012_20m.launch](https://github.com/tu-darmstadt-ros-pkg/hector_gazebo/blob/hydro-devel/hector_gazebo_worlds/launch/sick_robot_day_2012_20m.launch)
  SICK robot day 2012 scenario, arena with diameter of 20m.
- [sick_robot_day_2014.launch](https://github.com/tu-darmstadt-ros-pkg/hector_gazebo/blob/hydro-devel/hector_gazebo_worlds/launch/sick_robot_day_2014.launch)
  SICK robot day 2014 scenario
