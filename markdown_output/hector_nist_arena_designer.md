## Overview

This package provides Qt based GUI for designing simulation scenarios
mainly based on elements of NIST standard test arenas for response
robots. The GUI tool is independent from ROS and available in this
package for convenience. Scenarios are saved to a proprietary format and
can be exported to both electric gazebo and the new fuerte gazebo (.sdf)
formats.

An guide on how to extend the system with custom scenario elements can
be obtained by using the "help" menu.
