## The Basics

This package provides the set of agents initially available for
[HERB](http://personalrobotics.intel-research.net/projects/herb.php),
the Home Exploring Robot Butler at
[Intel Labs Pittsburgh](http://personalrobotics.intel-research.net/).

Although the set of skills might not be immediately useful for other
robots, because if addresses the specific HERB components, it might
still serve as a useful example if you are new to the behavior engine.

The agents must be executed in the environment created by luaagent.

You can find the newest version at
<http://github.com/timn/ros-herb_agents>.

It is part of the [behavior engine stack](behavior_engine).
