This package is part of the KnowRob knowledge processing system.

It contains utilities for Prolog:

-   Interface to the [Weka](http://www.cs.waikato.ac.nz/~ml/weka/) and
    [Mallet](http://mallet.cs.umass.edu/) machine learning libraries,
    whose algorithms can be applied to instances in KnowRob (in
    classifiers.pl)
-   jython-interface for Prolog (in jython.pl, deprecated for internal
    use)
-   Several small utility scripts (in util.pl)
-   Methods for computing different semantic similarity values
    (comp_similarity.pl)
