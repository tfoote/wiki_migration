## Overview

This package is part of the [ROS-Industrial](Industrial) program. It
contains message definitions used by other packages in the
[industrial_core](https://index.ros.org/p/industrial_core) metapackage.

## Contact us/Technical support

For questions about this package or ROS-Industrial in general, please
contact the developers by posting a message in the
[ROS-Industrial category](https://discourse.ros.org/c/ros-industrial) on
ROS Discourse.
