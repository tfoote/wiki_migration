ixblue_stdbin_decoder is a library to parse the iXblue standard bin
protocol which is the more generic input/output protocol for iXblue
inertial system. In this library the protocol is only parsed as output
protocol.

Please note that a
[ROS driver](https://github.com/ixblue/ixblue_ins_stdbin_driver) allows
to convert the protocol data into ROS messages thanks to this parsing
library.
