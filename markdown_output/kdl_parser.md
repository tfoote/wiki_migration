## What is the KDL parser

If you want to take advantage of the powerful features of the
[Kinematics and Dynamics Library](orocos_kinematics_dynamics), the kdl
parser provides an easy way to construct a full KDL Tree object.
Starting from either a [URDF xml description](urdf/XML) or a Collada xml
description of your robot, the kdl parser automatically generates a KDL
Tree.
