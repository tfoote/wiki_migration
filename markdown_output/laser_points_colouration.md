## Overview

This package is used to colour the 3D point cloud using the calibration
parameters.

## Usage

Running the following command to colour the 3D point cloud:

rosrun laser_points_colouration \[pcd_file_name\]

\[pcd_file_name\] : the file name of the point cloud to be coloured;
