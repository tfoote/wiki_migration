Package containing Orocos drivers for the KUKA LBR4 robot, based on the
KUKA.FastResearchInterface.

To use the KUKA.FastResearchInterface, you need a license from KUKA. To
compile the package, a header file from KUKA is required.

Via the OrocosRTT - ROS integration, the KUKA LBR4 robot can then used
within ROS applications.
