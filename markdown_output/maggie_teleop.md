## Overview

This package provides an launch file for running
[maggie_teleop](maggie_teleop) in a configuration that allows it to run
in parallel with the [navigation](navigation) stack on the
[Social Robot Maggie](Robots/Maggie).

## Building Blocks

-   **`teleop_joy.launch`**: launches the teleoperation by a joystick.
-   **`teleop_keyboard.launch`**: launches the teleoperation by a
    keyboard.
