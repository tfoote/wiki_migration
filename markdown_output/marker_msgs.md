## Overview

This package holds messages to describe markers with and without ids
detected by a system in a three or two dimensional space. In addition
messages are provided to publish markers with covariance which can be
used to describe a trained or known combination of markers.

## Visualization

With the help of the
[tuw-robotics/marker_rviz_plugin](https://github.com/tuw-robotics/marker_rviz_plugin)
the msgs can be visualized in rviz.
