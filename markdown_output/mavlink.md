# MAVLink

Communication library for various autopilot system. This package
contains both C-headers and pymavlink.

At least this packages use it\'s own bundled (or installed by pip)
mavlink headers or pymavlink: mavlink_ros, rospilot, roscopter,
autopilot_bridge, px4-ros-pkg.
