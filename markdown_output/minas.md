## Robot using minas package

[Youtube](https://www.youtube.com/watch?v=z17fV97dhEU)

## Overview

The minas pacakges contains basic control tools for MINAS-A5B EtherCAT
communication driver for indusdtrial robots Tra1 and its simulator with
the MoveIt! Motion Planning Framework.

## Install

On your `Ubuntu` machine where `ROS` [indigo](indigo) is installed:


```
$ sudo apt-get install ros-indigo-minas
```

 This command will have the following packages:

-   From `minas` package suite: [ethercat_manager](ethercat_manager),
    [minas_control](minas_control), [tra1_bringup](tra1_bringup),
    [tra1_description](tra1_description),
    [tra1_moveit_config](tra1_moveit_config)

## Running robots

[tra1_bringup](tra1_bringup) package wiki page shows how to run robots
virtually.
