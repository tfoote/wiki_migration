** OBSOLETE PACKAGE, DO NOT USE **

This package held a set of functions to convert between common ROS
messages and MRPT C++ classes, a functionality which is now (2022)
exposed directly via
[mrpt::ros1bridge](https://docs.mrpt.org/reference/latest/group_mrpt_ros1bridge_grp.html)
and
[mrpt::ros2bridge](https://docs.mrpt.org/reference/latest/group_mrpt_ros2bridge_grp.html)
C++ libraries, part of the
[mrpt2](https://index.ros.org/search/?term=mrpt2) ROS package.
