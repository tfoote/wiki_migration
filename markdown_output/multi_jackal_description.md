## Overview

\`multi_jackal_description\` contains the robot model description for a
[Clearpath Jackal](http://wiki.ros.org/Robots/Jackal). It has been
extended from the single robot
[jackal_description](http://wiki.ros.org/jackal_description) to separate
the robots into unique namespaces, allowing multiple robots to be
simulated at the same time.

## Tutorials

There are tutorials on how to spawn robots using this package in
[multi_jackal_tutorials](http://wiki.ros.org/multi_jackal_tutorials).
