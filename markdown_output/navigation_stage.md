## Overview

This package holds example launch files for running the
[navigation](navigation) stack in [stage](stage).

## Launch Files

-   \`launch/move_base_amcl_10cm.launch\`: Example launch file for
    running the [navigation](navigation) stack with [amcl](amcl) at a
    map resolution of 10cm.
-   \`launch/move_base_amcl_5cm.launch\`: Example launch file for
    running the [navigation](navigation) stack with [amcl](amcl) at a
    map resolution of 5cm.
-   \`launch/move_base_amcl_2.5cm.launch\`: Example launch file for
    running the [navigation](navigation) stack with [amcl](amcl) at a
    map resolution of 2.5cm.
-   \`launch/move_base_fake_localization_10cm.launch\`: Example launch
    file for running the [navigation](navigation) stack with
    [fake_localization](fake_localization) at a map resolution of 10cm.
-   \`launch/move_base_fake_localization_5cm.launch\`: Example launch
    file for running the [navigation](navigation) stack with
    [fake_localization](fake_localization) at a map resolution of 5cm.
-   \`launch/move_base_fake_localization_2.5cm.launch\`: Example launch
    file for running the [navigation](navigation) stack with
    [fake_localization](fake_localization) at a map resolution of 2.5cm.
-   \`launch/move_base_multi_robot.launch\`: Example launch file for
    running the [navigation](navigation) stack with multiple robots in
    [stage](stage).
-   \`launch/move_base_gmapping_5cm.launch\`: Example launch file for
    running the [navigation](navigation) stack with [gmapping](gmapping)
    at a map resolution of 5cm.
