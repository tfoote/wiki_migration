**OMPL is now a standalone library**. Please see
<http://ompl.kavrakilab.org> on how to use it directly. Please see
[MoveIt!](https://index.ros.org/p/moveit) for more on motion planning.

Please report issues / send contribution to
[OMPL development repository](https://bitbucket.org/ompl/ompl).

## Tutorials

Tutorials for OMPL can be found on the
[tutorials page](http://ompl.kavrakilab.org/documentation.html).

If you are working with a robot, tutorials for integrating OMPL with
your robot can be found in the ompl_ros_interface package
[tutorials](ompl_ros_interface/Tutorials).
