## Overview

This package contains launch files for using OpenNI-compliant devices in
ROS. It supports the Asus Xtion, Xtion Pro, and multiple version of the
Primesense 1.08 and 1.09 cameras. It does NOT support any versions of
the Kinect. [freenect_camera](https://index.ros.org/p/freenect_camera)
or [openni_camera](https://index.ros.org/p/openni_camera) is the
recommended driver for using a Kinect with ROS.

## Usage

It is recommended to use this driver through the launch files provided
in [openni2_launch](https://index.ros.org/p/openni2_launch)
