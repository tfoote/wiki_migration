## Overview

This is [osm-gps-map](http://nzjrs.github.com/osm-gps-map/) packaged for
a local ROS installation. This package is primarily to make it easier to
install [ground_station](ground_station) and [gpsd_viewer](gpsd_viewer).
More information about
[osm-gps-map](http://nzjrs.github.com/osm-gps-map/) can be found at
their home page.
