## Phantom Intelligence Sensors Driver

This is the documentation of the ROS driver for the
[Phantom Intelligence](http://phantomintelligence.com/) LiDAR sensors.
This driver uses Phantom Intelligence's
[Sensor Gateway](https://github.com/PhantomIntelligence/SensorGateway)
library (which contains different sensor driver implementations) and
provides access to their API through Phantom Intelligence
[unified sensor communication protocol](https://github.com/PhantomIntelligence/GatewayProtocol)
(which is still currently under development).

## Supported Sensors

-   AWL sensor family
-   Guardian sensor family
