## Overview

The [phidgets_ir](phidgets_ir) package contains a ROS driver for the
[ Phidgets IR](http://www.phidgets.com/products.php?product_id=1055_0 )
device. The driver does not publish any data in ROS, but can be used as
an example or adapted.
