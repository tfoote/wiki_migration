Temporary holding area for testing packages related to the
[Pi Robot Project](http://www.pirobot.org). Most of the code here is
highly unstable and rapidly changing. For more stable packages that have
been released please see:

-   [ROS By Example](https://github.com/pirobot/rbx1) - Sample code to
    accompany the book by the same name (Volume 1)
-   [ros_arduino_bridge](ros_arduino_bridge) - A ROS interface to the
    popular Arduino microcontroller
-   [pi_head_tracking_tutorial](pi_head_tracking_tutorial) - A ROS
    tutorial on tracking a colored object.
-   [pi_head_tracking_3d_part1](pi_head_tracking_3d_part1) - Pointing
    the head to a 3D location in space.
-   [pi_tracker](pi_tracker) - Skeleton tracking using a Kinect + OpenNI
    and Dynamixel servos
-   [skeleton_markers](skeleton_markers) - ROS package for displaying
    skeleton joint positions in RViz
-   [pi_face_tracker](pi_face_tracker) - Face tracking using ROS and
    OpenCV.
-   [serializer](serializer) - A ROS package to control the Serializer
    microcontroller
