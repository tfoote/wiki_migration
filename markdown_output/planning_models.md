## Overview

This package contains a set of classes that can be used to create a
representation of a robot for motion planning. The planning model can be
created directly from a URDF format. This robot representation is
currently used within the arm navigation stack for motion planning,
trajectory monitoring and for representation of the robot in a collision
space.
