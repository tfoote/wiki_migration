## ROS Interface

```clearsilver
name = polonius_interface
desc = GUI interface to Polonius
pub {
  0.name = cues
  0.type = polonius_msgs/Cue
  0.desc = All of the cues generated from the Engine
  1.name = updates
  1.type = polonius_msgs/InterfaceUpdate
  1.desc = Interface Updates 
}
sub {
  0.name = cues
  0.type = polonius_msgs/Cue
  0.type = Cues generated by the GUI
}
param {
  0.name = script
  0.type = String
  0.desc = Script specifying the interaction. See the [[polonius/Tutorials/Writing a Polonius Script|Writing a Polonius Script]] tutorial. 
  1.name = package
  1.type = String
  1.desc = Name of package where the actions are defined. 
  2.name = start_state
  2.type = String
  2.desc = Name of the initial state
```
