## Bring up the robot

As with all applications, you must first
[bring up your robot](https://index.ros.org/p/pr2_apps).

## Launching

Launch the mannequin mode: 

```
roslaunch pr2_mannequin_mode pr2_mannequin_mode.launch
```



Now you should be able to move both arms and the head around, and they
should stay put after you let go.
