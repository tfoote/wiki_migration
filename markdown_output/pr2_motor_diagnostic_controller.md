# Package Summary

-   Author: Rahul Udasi rudasi@willowgarage.com
-   Licence: BSD
-   Source:
    <https://github.com/rudasi/pr2_motor_diagnostic_controller.git>

This package works together with its counterpart computer package,
pr2_motor_diagnostic_tool. This package contains the PR2 motor
diagnostic real time controller which is used to get a Motor Sample
message from the list of actuators provided by the
pr2_motor_diagnostic_tool.
