# Package Summary

This package contains the PR2 diagnostic rqt plugin tool. This tool
works with its counterpart on the robot, the
pr2_motor_diagnostic_controller which is used to get data from the list
of actuators provided by this tool. This tool is used to detect PR2
motor faults such as bad encoders, unplugged encoders and cut motor
wires and plot graphs showing these.
