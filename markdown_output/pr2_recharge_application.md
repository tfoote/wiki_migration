## Recharge App

  -- -------------------------- -- ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- --
     ![](attachment:plug.png)      The recharge app allows you to select an outlet in the Willow Garage building and command the PR2 to recharge. The PR2 will drive to the outlet, plug in, and wait for the command to unplug. When PR2 is in the plugged in state, no other apps can be run until the PR2 is unplugged and the recharge app is stopped.
