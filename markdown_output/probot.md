## Overview

This stack provides ROS support for PROBOT. It currently contains
packages that provide nodes for communication with PROBOT controllers,
URDF models for various robot arms and the associated [MoveIt](moveit)
packages.

## Compatibility

The \`probot_driver\` package has been successfully used with system
versions \`v1.0.0\`.
