# quori_controller

[quori_controller](https://github.com/Quori-ROS/quori_ros/tree/master/src/quori_controller)
is a [ros_control](ros_control) compliant implementation of actuation
and motor feedback for the [Quori](Robots/Quori) robot platform. It
enables both holonomic and differential drive control of the RAMSIS
base.

## Documentation

Up-to-date documentation can be found on
[quori_controller's github page](https://github.com/Quori-ROS/quori_ros/blob/master/src/quori_controller/readme.md).
