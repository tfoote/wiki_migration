# quori_face

[quori_face](https://github.com/Quori-ROS/quori_ros/blob/master/src/quori_face)
allows ROS nodes to publish images to Quori's spherical projected face.
It also contains utilities for calibration of the projection mechanism.

## Documentation

Up-to-date documentation, including launch files, ROS parameters, and
ROS topics, can be found on
[quori_face's github page](https://github.com/Quori-ROS/quori_ros/blob/master/src/quori_face/readme.md).
