## About

The \`rail_pick_and_place\` metapackage contains packages for object
recognition, grasp selection, and placement. Also included are packages
for collecting demonstration grasps, generating models for recognition
and manipulation, and training to determine the effectiveness of learned
grasps.

## Installation

To install the \`rail_pick_and_place\` package, you can install from
source with the following commands:

. ```shell
cd /(your catkin workspace)/src
git clone https://github.com/WPI-RAIL/rail_pick_and_place.git
cd ..
catkin_make
```
