## Overview

This package is part of [rangeonly_driver](rangeonly_driver) stack. The
package contains generic ROS messages for range-only sensors.

## Messages

\'\'\'P2PRange:\'\'\' This message is used to store range-only
measurements between a pair of devices (i.e. distance measurements
between two sensors). The message includes other kind of information
like the type of range-only sensor technology (ultrsonic, radio-based,
etc), the unique identifiers of the ranging sensors, etc. As an example,
this message has been used with the [nanotron_swarm](nanotron_swarm)
driver for a radio-based range-only sensor in this
[dataset](http://grvc.us.es/staff/caba/roslam).
