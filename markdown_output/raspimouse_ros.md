# Raspberry Pi Mouse

日本語版wikiは[こちら](http://wiki.ros.org/ja/raspimouse_ros)です。

![\|align=\"right\",width=\"250\"](attachment:raspberrypimouse.png)

## Charastaristics

-   controllable with ROS
-   conforms to micro-mouse official convention regulation
-   hardware and software are both open sourced
