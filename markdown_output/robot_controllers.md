This package contains implementations of a number of controllers which
can be used with the
[robot_controllers_interface](https://index.ros.org/p/robot_controllers_interface)
framework. This is a robot control infrastructure, developed initially
for Fetch and Freight, but designed to be robot-agnostic.

Documentation is primarily
[Doxygen-generated](http://docs.ros.org/indigo/api/robot_controllers/html)
at this time.
