## Overview

This package allows robot administrators to quickly and easily generate
one or more background jobs to run roslaunch invocations on system
startup. You can use it directly from the command-line, or via a simple
Python API.

Please see usage and docs here:
<http://docs.ros.org/jade/api/robot_upstart/html/>
