This package provides a ROS driver for the Roboteq SDC21xx family of
motor controllers in a differential drive configuration.

Subscribes to cmd_vel, publishes to odom, and broadcasts odom tf.

Also publishes sensor data to some ancillary topics including
roboteq/voltage, roboteq/current, roboteq/energy, and
roboteq/temperature.

Does not require any MicroBasic script to operate.
