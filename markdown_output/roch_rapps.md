## Overview

roch_rapps package beyond on [roch](roch) stack package and provides
some qt GUI for user control Roch easily.

Due to [rocon](rocon) will has a big change with framework, so we just
adjust roch_rapps with new rocon version for pre-release, For now just
implement GUI for start with non-command and also need enter few command
then you can use turn on/off capabilities with Roch.
