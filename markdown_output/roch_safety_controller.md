## Overview

This package is usually used by [roch_bringup](roch_bringup) and also
can run individual. Mainly used by [roch_navigation](roch_navigation)
which can provide safety control for avoid obstacles.

For using this package, please see
[Using package of roch_safety_controller](roch_robot/Tutorials/Using package of roch_safety_controller).
