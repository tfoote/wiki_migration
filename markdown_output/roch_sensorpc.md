## Overview

This package provide a publisher for sensor data which can publish point
cloud around Roch in [roch_navigation](roch_navigation) or individual.

Whether send point cloud or not depend on sensor data such as psd,
ultrasonic, cliff in [roch_base](roch_base), which if sensor data less
than threshold value given.
