## Documentation

This stack package of roch_simulator is part of [Roch](Robots/Roch),
mainly provides simulator with Roch without real Roch.

For now, just support [Gazebo](gazebo) simulator and will support more
simulators such as [stdr_simulator](stdr_simulator), [stage](stage) and
etc in the future.

For how to using simulators with Roch, please see
[tutorials](roch_simulator/Tutorials) for more information.

### Geometric Packages

-   [roch_gazebo](roch_gazebo) - Gazebo plugin definitions and
    extensions to the robot URDF.
-   Primary simulation in Gazebo simulator with ROS.
