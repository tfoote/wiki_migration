## Overview

A rapp is a robot (or ROCON) application which is executable by the
[rocon_app_manager](rocon_app_manager). rocon_app_utilities provides a
rapp indexer and command line tool to introspect rapps. Please refer to
[Code API Document](http://docs.ros.org/indigo/api/rocon_app_utilities/html/)
for a detailed specification of rapps.
