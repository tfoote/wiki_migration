This package contains a simple python node that when configured, exposes
some basic information about the current system (i.e. ros master) to
clients that wish to introspect. This is typically only useful to
applications such as the [rocon_remocon](rocon_remocon) which need a
unique name to store, and a description/icon to relay to the human user
of the remocon.
