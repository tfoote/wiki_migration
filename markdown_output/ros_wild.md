## Overview

Package ros_wild provides wildcard Subscriber and Publisher for ROS
(Python only).

## Installation

### via apt

```
$ sudo apt install ros-kinetic-ros-wild
```

### from source

```
$ cd /path/to/your/catkin_ws/src/
$ git clone https://github.com/yuma-m/ros_wild.git
$ cd ../
$ catkin_make
```
