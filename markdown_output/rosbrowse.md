## Overview

\`rosbrowse\` currently just contains a set of certificates to access
projects on sourceforge.

\`rosbrowse\` used to track public ROS repositories and build the
\'\'megamanifest\'\', which powers tools like [roslocate](roslocate) and
the [ROS.org browse tool](http://www.ros.org/browse/). But the scripts
have been moved to rosdoc_rosorg.
