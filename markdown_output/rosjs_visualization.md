# Overview

This is a package that provides libraries of functionality that allows
users to create web visualizations of robot data using Javascript. To
include the functionality visualization.js should be added as a script
to the HTML.

# Provided Functionality

## Visualization Manager

A visualization manager can be created for a canvas object in order to
display 3d visualizations. New visualizations topics can be added to the
canvas object using the visualization manager. Please refer to the
following
[ tutorial ](http://www.ros.org/wiki/rosjs_tutorials/Tutorials/Visualization)
for more information.
