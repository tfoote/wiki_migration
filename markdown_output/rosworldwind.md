## Overview

The rosworldwind package provides a simple GUI to display geo-referenced
information on a virtual globe using the NASA World Wind technology.

![\|height=\"408px\",width=\"700px\"](http://rosworldwind.googlecode.com/files/Screenshot-ROS WorldWind Adapter.png)

### NASA World Wind

NASA World Wind is a virtual 3D globe open source development based on
Java. The user can interact with the virtual globe by changing the view
by moving, zooming, tilting, rotating. Further information on NASA World
Wind can be found here: <http://worldwind.arc.nasa.gov/java/> and
<http://goworldwind.org/>
