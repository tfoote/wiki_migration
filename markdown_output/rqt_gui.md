### Advantage of using rqt_gui

`rqt_gui` upon using multiple `rqt` plugins has following
advantages:

-   Multiple `rqt` plugins can be docked into a single window
-   Layout can be flexibly customized
-   Each plugin pane can be stripped out from `rqt_gui` and floated
    around
-   The perspective (plugins opened and their positions, sizes) from
    previous runtime can be restored
