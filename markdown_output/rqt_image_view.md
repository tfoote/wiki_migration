`rqt_image_view` is an `rqt` version of [image_view](image_view)
(however, as of Mar 2015, they are separately implemented and there's
no dependency in-between each package. See
[this ticket](https://github.com/ros-perception/image_pipeline/issues/158#issuecomment-157524991)
for more info).

![ launch top window \| width=500](attachment:snap_rqt_image_view_1.png )

[rqt_gui](rqt_gui) allows you to open multiple `rqt_image_view`
windows and dock into a single window like this.
