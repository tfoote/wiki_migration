A successor of [pr2_dashboard](pr2_dashboard) with enhancements based on
`rqt` framework.

## Install

Install by:



```
$ sudo apt-get install ros-%YOUR_ROS_DISTRO%-rqt-pr2-dashboard
$ sudo apt-get install ros-groovy-rqt-pr2-dashboard   (an example in Groovy)
```

 You may also need to run:


```
$ rosdep update
$ rosdep install rqt_pr2_dashboard
```



(see [here](https://index.ros.org/p/rqt) for more installation details)
