## Description

This metapackage provides packages:

-   **rsv_balance_viz** - Visualization configurations for RVIZ and
    respective launch files.
-   URDF model visualization. ```
roslaunch rsv_balance_viz view_model.launch
```
-   Robot model visualization ```
roslaunch rsv_balance_viz view_robot.launch
```
-   **rsv_balance_rqt** - RQT plugin for setting the platform's
    operation mode.
