# Rviz for Android

![](attachment:screenshot_pr2.png)

Rviz for Android is a version of [Rviz](Rviz) written in Java for
Android tablets. It uses the ROSJava API to receive ROS messages and a
custom made OpenGL ES 2.0 3D rendering engine.

Any tablet running Android 3.2 is supported. Tutorials, source code, and
ready to install APK file are available on
[the Rviz for Android BitBucket repository](https://bitbucket.org/zimmrmn3/rviz-for-android/)
