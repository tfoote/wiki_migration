## Details

The [rviz_imu_plugin](rviz_imu_plugin) package is used to display
[sensor_msgs/msg/Imu](https://docs.ros.org/en/rolling/p/sensor_msgs/msg/Imu.html)
messages in [rviz](rviz). Once you download and compile the package, it
should be visible as a plugin.

It displays the orientation of the IMU using a box as well as and
coordinate axes. The acceleration can be visualized using a vector.

The package has been
[ ticketed](https://code.ros.org/trac/ros-pkg/ticket/5476 ) for
inclusion in ROS.
