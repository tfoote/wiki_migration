## Usage/Examples

The configuration for [schunk_powercube_chain](schunk_powercube_chain)
and [schunk_sdh](schunk_sdh) is done in
[schunk_hardware_config](schunk_hardware_config). After setting up the
correct configuration, start the components with
```
roslaunch schunk_bringup lwa_solo.launch
``` or ```
roslaunch schunk_bringup sdh_solo.launch
```
