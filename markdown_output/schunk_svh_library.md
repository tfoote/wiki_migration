# Overview

This is a standalone C++ library to control the Schunk SVH 5-finger
hand. It provides a hardware abstraction for driver development. Users
can wrap this library in their preferred robotics framework. Check
[this driver](https://github.com/SCHUNK-GmbH-Co-KG/schunk_svh_ros_driver)
as an example for ROS1 and ROS2.
