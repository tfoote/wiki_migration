# Overview

This is a standalone C++ library to interface SICK\'s safeVisionary2
cameras. Users can wrap this library in their preferred robotics
framework. Check
[ this driver](https://github.com/SICKAG/sick_safevisionary_ros1) for an
example in ROS1.
