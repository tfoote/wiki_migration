## Nodes

```clearsilver
node.0{
name=smi540_node
desc= The `smi540_node` interfaces with Bosch SMI530/540 3-axis sensor (x-accel, y-accel, z-gyro). The driver requires an [[http://www.xdimax.com/sub20/sub20.html|Xdimax SUB-20 Device]] to communicate with the SPI interface of the SMI530/540. The SMI530 and SMI540 are identical sensors.  

param {
  0.name= ~rate_Hz
  0.default=`100`
  0.type= double
  0.desc= sampling rate of sensor 
}
pub {
  0.name= ~<name>/smi540
  0.type= smi540/smi540meas
  0.desc= acceleration data in [g] for x, y, rotation rate in z axis [deg/s]
}
```
