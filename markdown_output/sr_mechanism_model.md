## Overview

We needed to redefine the
[transmissions](http://www.ros.org/wiki/pr2_mechanism_model) used in the
[model](sr_hand), to be able to combine the distal and middle phalanges
of the fingers into joint 0s. The new transmissions are defined in this
package. They\'re using the actuators which are defined in
[sr_robot_lib](sr_robot_lib).
