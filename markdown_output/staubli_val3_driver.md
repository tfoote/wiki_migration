## Overview

This is a VAL 3 based driver for use with CS8 controllers and Staubli
6-axis manipulators. See the
[package README](https://github.com/ros-industrial/staubli_val3_driver/blob/master/staubli_val3_driver/README.md)
for more information.

## Tutorials

Tutorials detailing the installation and setup of the packages will be
made available at a later date.

For the generic ROS-Industrial tutorials, please see the ROS-Industrial
[training exercises](https://industrial-training-master.readthedocs.io/en/melodic).
