## Package Summary

This package contains the different controllers and launch files for the
[SummitX robot](Robots/SummitX), shared for real robot and simulation.

-   Autor: Robotnik Automation
-   License: BSD
-   Source: git
    <https://github.com/RobotnikAutomation/summit_x_common.git>

![SummitX RViz\|width=\"600px\"](attachment:summit_x_rviz.png)

## List of packages

### summit_xl_description

The urdf, meshes, and other elements needed in the description are
contained here. The package includes also some launch files to publish
the robot state and to test the urdf files in rviz.
