This package contains the following controllers, used for teleoperating
the PR2.

-   [JTTeleopController](teleop_controllers/JTTeleopController) which
    follows cartesian setpoints with a Jacboian-transpose control law.
-   [JinvTeleopController](teleop_controllers/JinvTeleopController)
    which follows cartesian setpoints with a Jacboian-inverse control
    law.

Note: this package has been replaced in electric with
<http://www.ros.org/wiki/robot_mechanism_controllers>
