## Overview

The `test_diagnostic_aggregator` package is used for testing and
development of the
[diagnostic_aggregator](https://index.ros.org/p/diagnostic_aggregator).
It has no public API and no usable nodes or libraries.

## Tutorials

This package has no tutorials. See
[Diagnostic Aggregator Tutorials](https://index.ros.org/p/diagnostic_aggregator)
for tutorials on the
[diagnostic_aggregator](https://index.ros.org/p/diagnostic_aggregator).

## Troubleshooting

The `test_diagnostic_aggregator` package has no troubleshooting tips.
See
[Diagnostic Aggregator (Troubleshooting)](https://index.ros.org/p/diagnostic_aggregator)
for more information.
