## Documentation

This package allows to convert pointcloud2 messages through a
geometry_msgs::Transform.

### Supported Data Extractions

  -- ------------------------------------------------------------------------------------------------ -- -------------------- --
     ROS message type                                                                                    Datatype extracted   
     [sensor_msgs::PointCloud2](http://docs.ros.org/jade/api/sensor_msgs/html/msg/PointCloud2.html)      ros::Time            
     [sensor_msgs::PointCloud2](http://docs.ros.org/jade/api/sensor_msgs/html/msg/PointCloud2.html)      std::string          
  -- ------------------------------------------------------------------------------------------------ -- -------------------- --

### How to use

Please see the Code API documentation (top right of this page) for use.
