## Launch Files

` launch/arm.launch ` Brings up the [arbotix](arbotix) driver for
interfacing with the arbotix board and publishing joint states.

` launch/fake-arm.launch ` Simulation version of arm.launch. Starts a
fake version of the [arbotix](arbotix) driver that just changes joint
states values.

{}

## Configuration Files

` config/arm.yaml ` See the documentation for the
[arbotix_python](arbotix_python#Configuration) package for a description
of the parameters.
