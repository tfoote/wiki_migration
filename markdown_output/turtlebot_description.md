### Package Organization

This package contains robot description files for TurtleBot, organized
into subdirectories as follows:

-   \`urdf/\` contains ([xacro](xacro) representations of) [urdf](urdf)
    descriptions of various parts of the !TurtleBot (hardware, sensors,
    and base).
-   \`meshes/\` contains mesh files (\`.stl\`, \`.dae\`, \`.3ds\`) for
    visualization and collision properties.
