## Overview

This package contains additional experiments used to test
[twoLevelMTTD](twoLevelMTTD) algorithm. These experiments could be
considered \`stand alone\`, infact they just used OROCOS component. In
order to visualize results, Ipython is needed.

## Experiments

The main goals of these experiment are: (i) give a proof about
twoLevelMTTD capabilities, (ii) show how to use twoLevelMTTD OROCOS
components. Further information could be found on Tutorials or
<http://people.mech.kuleuven.be/~tdelaet/twoLevelMTTD/index.html>
