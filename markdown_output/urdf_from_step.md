## Overview

This is ROS package for automated conversion of STEP models to URDF
format. The program takes as input the STEP file of the desired robot or
robot-like maschine and creates a new ROS package. The package created
contains the URDF description, the STL mesh files required by URDF
description, and the ROS launch file to load the data into the ROS
control system.
