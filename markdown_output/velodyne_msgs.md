## Overview

This package collects all ROS messages that are specific to Velodyne 3D
LIDARs, simplifying the dependencies between [velodyne](velodyne) stack
components and their users.

It also provides bag migration scripts for translating old captured data
to the latest format using the [rosbag fix](rosbag/Commandline#fix)
command.
