## Overview

This package collects all ROS messages that are specific to Velodyne 3D
LIDARs, simplifying the dependencies between
[velodyne](https://index.ros.org/p/velodyne) stack components and their
users.

It also provides bag migration scripts for translating old captured data
to the latest format using the
[rosbag fix](https://index.ros.org/p/rosbag) command.
