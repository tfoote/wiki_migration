This is the ROS-Package for libviso2, a library for visual odometry
created by Andeas Geiger from the Institute of Measurement and Control
Systems at Karlsruhe Institute of Technology.

Apart from the original libviso2 sources, this package contains
CMakeFile for easier integration into the ROS build system.

See the [viso2_ros](viso2_ros) package for ros nodes that wrap this
library.
