## Description

This package contains various robot apps (rapps) that can be used by
!WheeledRobin or any TurtleBot compatible robot. Rapps are used by the
appmanager started by 'minimal_with_appmanager' or 'bringup.concert'
in [wheeled_robin_bringup](wheeled_robin_bringup) package.

## Rapps

### Thrustmaster Teleop

Control the WheeledRobin with a Thrustmaster Joystick. Rapp Platform:
linux.ros.turtlebot
