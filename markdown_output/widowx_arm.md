## Package Summary

This package contains the different controllers and description files
for
[ WidowX robotic arm](http://www.trossenrobotics.com/widowxrobotarm )

-   Autor: Robotnik Automation
-   License: BSD
-   Source: git <https://github.com/RobotnikAutomation/widowx_arm.git>

![WidowX\|width="600px"](attachment:widowx.jpg)

## List of packages

### widowx_arm_controller

The code and scripts for controlling the robotic arm.

### widowx_arm_description

The urdf, meshes, and other elements needed in the description are
contained here.
