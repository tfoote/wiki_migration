## Getting Started

Just download the precompiled debian for your ros distro (e.g. kinetic)
and playback the bag files: ```
$ sudo apt-get install ros-kinetic-xpp
$ roslaunch xpp_examples hyq_bag.launch
``` Also you can always
clone the repo into your catkin workspace and build from source, as
described [here](https://github.com/leggedrobotics/xpp).

## Generating messages

The more involved example trajectories shown have been generated with
[towr](towr), an optimizer for legged robot motions. However, simple
motion plans can also be generated by hand as shown below. This example
is taken from
[xpp_examples/monoped_pub.cc](https://github.com/leggedrobotics/xpp/blob/12b1dbd0aa72aabcb473a8946ce4828f4d53bde8/xpp_examples/src/monoped_pub.cc).
Run it using ```
$ roslaunch xpp_examples monoped_ex_generate.launch
```

```cplusplus
#include <ros/ros.h>
#include <xpp_msgs/RobotStateCartesian.h>
#include <xpp_states/robot_state_cartesian.h>
#include <xpp_states/convert.h>

using namespace xpp;

int main(int argc, char *argv[])
{
  ros::init(argc, argv, "hopper_publisher");
  ros::NodeHandle n;
  ros::Publisher state_pub = n.advertise<xpp_msgs::RobotStateCartesian>("state", 1);

  // visualize the state of a one-legged hopper
  RobotStateCartesian hopper(1);

  // publishes a sequence of states for a total duration of T spaced 0.01s apart.
  double T = 2.0;
  double t = 0.0;
  double dt = 0.01;
  while (t < T)
  {
    // base and foot follow half a sine motion up and down
    hopper.base_.lin.p_.z()        = 0.7 - 0.05*sin(M_PI/T*t);
    hopper.ee_motion_.at(0).p_.z() = 0.1*sin(M_PI/T*t);
    hopper.ee_forces_.at(0).z()    = 100;  // Newtons
    hopper.ee_contact_.at(0)       = true; // leg in contact

    state_pub.publish(Convert::ToRos(hopper));

    ros::spinOnce();
    ros::Duration(dt).sleep(); // pause loop so visualization has correct speed.
    t += dt;
  }
}
```

## Plot the motions

The visualized trajectories in the rosbags can be easily plotted.
```
$ roscd xpp_examples/bags/
$ rqt_bag hyq.bag
``` Then simply right-click on `xpp/state_des`
and `View` -> `Plot`.

## Visualize your own robot

To visualize your own URDF is very easy to setup. A minimal example to
follow can be seen
here:[urdf_visualizer_hyq1.cc](https://github.com/leggedrobotics/xpp/blob/master/robots/xpp_hyq/src/exe/urdf_visualizer_hyq1.cc).

-   Upload your [urdf](urdf) to the ROS parameter server
    [(example)](https://github.com/leggedrobotics/xpp/blob/master/robots/xpp_hyq/launch/monoped.launch).
    ```xml
 <param name="name_of_your_urdf_model_given" 
   command="$(find xacro)/xacro '$(find xpp_your_robot)/urdf/your_robot.urdf'"/>
```

## Packages Overview

The core packages that this ROS stack offers are:

-   **[xpp_states](xpp_states):** Classes to define robot states in
    cartesian and joint space.
-   **[xpp_msgs](xpp_msgs):** ROS message representation of the above
    states.
-   **[xpp_vis](xpp_vis):** Visualization of states and robots through
    [rviz](rviz).

Some optional packages include:

-   **[xpp_examples](xpp_examples):** Some examples of how to generate
    and visualize motion plans in [rviz](rviz).
-   **[xpp_hyq](xpp_hyq):** [urdf](urdf) file and inverse kinematics
    functions to display the HyQ robot with 1,2 or 4 legs in
    [rviz](rviz).
-   **[xpp_quadrotor](xpp_quadrotor):** [urdf](urdf) file of a quadrotor
    used in one of the [xpp_examples](xpp_examples).
