## Overview

### Laser projections

The visualizer is based on
[ visualization_msgs/Marker](http://docs.ros.org/en/api/visualization_msgs/html/msg/Marker.html )
to simulate the laser projection of figures defined by the user. For
example lines, circles, text, etc.

### Reference systems

The visualizer also uses [tf](http://wiki.ros.org/tf) package to place
the origin axes of the active user-defined reference system and the
projector reference system. Read more info in
[z_laser_zlp1/Reference coordinate systems](http://wiki.ros.org/z_laser_zlp1#Reference_coordinate_systems)
